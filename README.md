# Hi, I'm Arvind 👋

I'm a **full-stack developer** based in Chandigarh, India, with **15+ years** of building web apps for clients around the world. Most of my work today is **multi-tenant SaaS** with **React/TypeScript** on the front end and **Laravel** or **Node.js** on the back end. I like the parts of a product that have to be reliable: billing, integrations, permissions and data that people depend on.

I've been with **RegalBit Solutions** since 2017, and I've freelanced on Upwork since 2016.

## 🔭 What I'm working on

- **[ShiftNinja](https://shiftninja.co/)**: a multi-tenant workforce scheduling SaaS (React, TypeScript, Laravel). I'm building out the real-time chat system, with Firebase and email notifications, pinned messages, edit/delete, and unread counts across DMs and groups.
- **[LiquorExam PAYG](https://www.payg.liquorexam.com/)**: a pay-as-you-go billing backend in Node.js/Express and PostgreSQL, with idempotent payments, retry queues and an automated test suite for billing scenarios.
- **Ref Analytics**: an AI chatbot that answers plain-English questions about NBA referees, fouls, players and teams, using the OpenAI API on top of a large sports database.
- **AI-assisted development**: I use **Claude Code** daily for agentic coding, browser testing and writing unit tests, and I review everything it produces before it ships.

## 💼 Other things I've built

- A **digital signature portal** (Angular 15, Laravel) with signing workflows and audit trails
- A **satellite imagery search platform** with map drawing tools in CesiumJS, KML/KMZ and GeoJSON processing, and a wallet system
- **GymVue**, a multi-tenant gym management SaaS with Stripe subscriptions and door hardware access through the OpenPath API
- **CRM integrations** with Salesforce and HubSpot using REST APIs and webhooks
- A **one-click report generator** that cut report delivery from a week to seconds, using Laravel queues and AWS CloudWatch
- An **Ionic mobile app** with Stripe and PayPal payments
